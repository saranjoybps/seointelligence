# SEO Intelligence Platform

Full-stack AI-powered SEO and digital marketing analysis platform.

## Stack
- Backend: FastAPI + async crawler + Ollama integration
- Frontend: Next.js 14 + TypeScript + Tailwind CSS

## Run

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
